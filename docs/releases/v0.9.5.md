# AviUtl2 API / Live Bridge 0.9.5

0.9.5は、Live Bridgeを「低水準APIを組み立てて操作する機能」から、AIエージェントや
通常のPythonコードが短く安全に動画編集へ使える高水準APIへ進める大型更新です。
既存の`LiveClient`とprotocol v1には後方互換性があり、raw操作が必要な場合の
escape hatchとして引き続き利用できます。

## インストール・更新

Python package:

```powershell
python -m pip install --upgrade aviutl2-api==0.9.5
```

Live Bridgeを使う場合は、このReleaseの`AviUtl2LiveBridge.aux2`もダウンロードして
既存pluginと置き換え、AviUtl2を再起動してください。対象ウィンドウの
`設定 > 外部API連携設定...`から連携をONにします。連携はウィンドウごとに既定OFFです。

## 新しい標準入口: `LiveProject`

revision、operation ID、snapshot更新、GUI cursor、空きlayer、media duration、
Effect selectorを呼び出し側で管理せず、短いコードで編集できます。

```python
from aviutl2_api.editing import effect
from aviutl2_api.live import LiveProject

with LiveProject.connect(pid=46016) as project:
    title = project.add_text(
        "第一章",
        duration=90,
        y=-200,
        size=80,
        effects=[
            effect("glow", strength=50, color="#FFD966"),
            effect("outline", size_px=4, color="#202040"),
        ],
    )
    title = project.update(title.primary, x=120, scale=110, opacity=0.9)
    png = project.render(title.primary.midpoint).png
```

`at`省略時はAviUtl2の現在cursor frame、`layer`省略時はLayer 0から見つけた最初の
未ロック・非衝突layerを使います。相対素材pathはPython processのcurrent working
directoryを基準に解決されます。render結果は既定でmemoryに返り、ファイルやprojectを
自動保存しません。

主な高水準操作:

- `add_text/image/video/audio/media/shape()`
- `find()`, `refresh()`, `summary()`, `preflight()`
- `update()`, `move()`, `delete()`
- `split()`, `trim()`, `set_duration()`
- `apply_effect()`, `update_effect()`と既存Effectの有効化・削除・並べ替え
- `render()`, `contact_sheet()`, `render_audio()`, `audio_review()`

## 複数操作: `EditPlan`

複数の作成・更新・削除・Effect操作を先に検証し、成功時は原則一つのAviUtl2 GUI
Undo単位として適用します。

```python
from aviutl2_api.editing import EditPlan, PlanValidationError, effect
from aviutl2_api.live import LiveProject

plan = EditPlan(sequence="parallel")
plan.add_video("intro.mp4", key="intro")
plan.add_text(
    "第一章",
    key="title",
    duration=90,
    y=-200,
    size=80,
    effects=[effect("glow", strength=50)],
)

with LiveProject.connect(pid=46016) as project:
    validation = project.validate(plan)
    if not validation.valid:
        raise PlanValidationError(validation)
    result = project.apply(plan)
    print(result.revision, result.undo_grouped, result.warnings)
```

- `sequence="parallel"`: 省略された配置を同じframe・別layerへ並べます。
- `sequence="serial"`: 追加順にtimeline上へ直列配置します。
- `at="end"`: timeline末尾へ配置します。
- 成功済み`EditPlan`はsingle-useです。
- SDKに完全transaction rollbackがないため、結果の`atomic`は`False`です。失敗時は
  `PlanApplyError.result.rollback`と`gui_undo_required`を必ず確認してください。

## 主要20 Effectのsemantic API

`effect(profile, ...)`は英語profile名とpixel、degree、seconds、`0.0..1.0` opacity、
`#RRGGBB`などの自然な値を、完全なAviUtl2 Effect item列へ変換します。Effect名・
item名・enumを推測せず、実機catalogとreadbackが一致しなければ成功扱いにしません。

対応profile:

- 色: `color_adjustment`, `monochrome`, `gradient`
- 加工: `crop`, `mask`, `resize`, `mosaic`
- ぼかし: `blur`, `directional_blur`, `motion_blur`
- 光・装飾: `glow`, `emission`, `outline`, `drop_shadow`
- key・出入り: `chroma_key`, `luminance_key`, `fade`, `wipe`
- 音声: `audio_gain`, `audio_fade`

同じspecを内部`.aup2`モデルにも利用できます。

```python
from aviutl2_api import apply_effects, validate_standard_effects
from aviutl2_api.editing import effect

apply_effects(
    project_model,
    timeline_object,
    effect("glow", strength=50, color="#FFD966"),
    effect("outline", size_px=4),
)
assert validate_standard_effects(project_model).valid
```

manifest IDは`2001901`です。生成project version `2001901`と、AviUtl2がOpen/Save後に
更新する`2010200`を明示的に互換扱いし、未知の将来versionはfail closedします。

## Native mediaとMP4

AviUtl2 native loaderが映像・音声を別objectとして作る形式と、
`動画ファイル → 映像再生`の一つのcombined objectとして作る形式の両方に対応しました。
動画transformは`映像再生`へ、映像Effectと音声Effectは実際のobject構成に合わせて
振り分けます。実機MP4で`glow`と`audio_gain`を同じcombined objectへ適用し、保存後の
`.aup2`、native PNG、PCM解析で確認しています。

## 検索・review・安全性

- `find()`はname、text、file、effect、layer、frame交差、API lockで検索できます。
- object参照はrevision scopedです。mutation後は返されたfresh参照を使います。
- native PNG/contact sheetとstereo float PCMをmemoryで取得できます。
- object/layer/effect lockをAPIから解除しません。
- 一般textを字幕と推測しなくなりました。字幕overlap診断はsubtitle layerと
  `subtitle_overlap="warn"`または`"error"`を明示した場合だけ行います。

## 互換性と既知の制約

- `LiveClient`と既存protocol v1 endpointは維持されています。
- 0.9.4 pluginへの単発Effect fallbackはありますが、create-time Effect stackは
  複数Undoへ分解せず`CapabilityUnavailableError`で拒否します。
- project open/save/save-as、encoder/export、preview playback、API lock解除は
  意図的に提供していません。
- 現行公式SDKにscene list/create/duplicate/switchとUndo/Redo実行APIがないため、
  これらのcapabilityはfalseであり、1.0 release gateはまだ閉じています。
